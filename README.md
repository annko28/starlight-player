# Starlight Player

## GitHub Pages で公開する手順
1. このフォルダの中身（index.html など6ファイル）をGitHubリポジトリの直下にアップロード
2. Settings → Pages → Branch を main / (root) にして Save
3. 表示されたURL（https://ユーザー名.github.io/リポジトリ名/）をiPhoneのSafariで開く
4. 共有ボタン → 「ホーム画面に追加」

## 使い方のコツ
- 保存した動画はホーム画面に追加したアプリ内に残ります（Safariのタブだけで使うと、iOSが一定期間後に消すことがあります）
- 長時間の動画も、ファイルをそのまま再生するため問題なく再生できます
- 画面を閉じても聞きたい場合は「Audio only」をオンにしてください
